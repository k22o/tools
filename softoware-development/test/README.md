#  テスト

## テストの種類

| テスト種別 | 確認内容 |
| --- | --- | 
| 機能テスト | 機能が正しいか| 
| パフォーマンステスト(負荷テスト) |　想定したパフォーマンスがだせているか | 
| システムテスト | 互換性の確認 | 
| ユーザビリティテスト | UIや使いやすさ  | 
| 運用テスト | 運用時の信頼性 | 
| セキュリティテスト | セキュリティ | 
| 静的解析 | コードの保守性 | 
| インストール・バージョンアップテスト | 移植性 | 

## 機能テストについて

テストピラミッドで有名なように以下の3段階で行う

- 単体テスト (-> 詳細設計に該当)
- インテグレーションテスト (-> 基本設計に該当)
- e2eテスト (-> 要件定義に該当)

これらのテストを自動化しておくことで、ソフトウェア修正時の退行確認 (リグレッションテスト) になる。
