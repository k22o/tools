# Storage

- block storage: OSやDBなど、低レイテンシ・高IOPSが求められる用途向けに、固定長のブロック単位でデータを読み書きするストレージ
- file storage: ディレクトリ階層(ファイルシステム)でデータを管理し、複数インスタンスから同時マウントして共有できるストレージ
- object storage: キーとメタデータを持つオブジェクト単位でデータを管理する、フラットな構造かつ容量無制限のストレージ。HTTP(S)経由でアクセスする

## S3 (Simple Stroage Service)

- バケットと呼ばれる単位でオブジェクト(データ)を格納する Object Storage
- バージョニング: 同一キーへの上書き・削除時に旧バージョンを保持し、誤削除・誤上書きから復旧できる
- ライフサイクル管理: 一定期間経過後に、別のストレージクラスへの移行や削除を自動化するルールを設定できる
- アクセス制御
   - バケットポリシー / IAMポリシー: JSON形式でバケットやオブジェクト単位のアクセス許可を設定
   - ブロックパブリックアクセス: 意図しない公開設定を防止する
- 静的Webサイトホスティング機能を持つ
